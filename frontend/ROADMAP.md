# MedQuery AI

## Overview

MedQuery AI is a cloud-native, AI-powered healthcare platform designed to provide secure, intelligent, and compliant medical information services. The platform combines modern web technologies, artificial intelligence, cloud infrastructure, and DevOps practices to deliver a scalable healthcare solution while following security best practices inspired by HIPAA and SOC 2 compliance principles.

This project serves both as a production-style software engineering project and as a portfolio demonstrating expertise in:

- React + TypeScript
- FastAPI
- Artificial Intelligence & Machine Learning
- Retrieval-Augmented Generation (RAG)
- AWS Cloud
- Docker
- Kubernetes
- Terraform
- CI/CD Automation
- PostgreSQL
- REST API Development
- Cloud Security

---

# Vision

Build a secure healthcare platform that enables patients and healthcare providers to access trustworthy medical information through AI while demonstrating enterprise software engineering best practices.
